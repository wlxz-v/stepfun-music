# 歌词写法

## 结构标签

标签**独占一行**，本身不进唱词。可用的标签：

```
[Intro] [Verse 1] [Verse 2] [Pre-Chorus] [Chorus 1] [Chorus 2]
[Bridge] [Instrumental] [Hook] [Break] [Drop] [Ad-lib] [Outro]
```

典型流行曲骨架：

```
[Intro]
[Verse 1]
主歌一
[Pre-Chorus]
预副歌
[Chorus 1]
副歌
[Verse 2]
主歌二
[Pre-Chorus]
[Chorus 2]
[Bridge]
桥段
[Chorus 3]
[Outro]
```

`[Instrumental]` 段下面不写词，模型自己加过门或间奏——想让曲子有呼吸感就插一段。

## 写作要点

**长度匹配风格**。一首 2 分钟的歌，主歌 4–8 行、副歌 4 行左右就够。写太长长到
`--maxtokens` 上限会被截断，副歌可能出不完整。

**副歌要能独立成立**。听一遍能记住的那句放副歌第一行。别把最重要的词埋在主歌第三段。

**中文歌注意齿音和闭口音**。`是/次/四/自` 这类字在快节奏里容易糊，密集处换开口字
（`爱/海/开/光`）会好唱很多。

**避免同音字连缀**。`一次一次一次又一次` 这种模型容易唱混。

**押韵不必强行**。现代流行大量半押和不押，硬押会写出很别扭的句子。

**和 caption 的情绪对齐**。caption 写 `melancholic`，歌词就别写派对狂欢——两者打架
时模型通常跟 caption 走，歌词会显得割裂。

## 敏感内容

提交阶段有内容审核（HTTP 451），生成阶段也可能 `error.stage=censor`。
明显的暴力、极端政治、 explicit 内容会被拦。边界模糊的最好先问用户要不要改。

## 完整示例

```
[Intro]

[Verse 1]
凌晨三点的便利商店
关东煮的热气爬上玻璃
我把手插进口袋里
假装一点都不冷

[Pre-Chorus]
城市把所有人都催着长大
只有这一刻 时间停下来

[Chorus 1]
就这样慢慢走吧
不用着急去哪里
路灯一盏一盏替我们数着
这条走了无数次的街

[Verse 2]
你说的那句话我还想着
像含在嘴里的糖
舍不得咽下去

[Chorus 2]
就这样慢慢走吧
就算明天照样糟糕
至少这一刻风是暖的
你还在我身旁

[Bridge]

[Outro]
慢慢走吧
慢慢走吧
```
