# 反问环节：选项库

用户说得模糊时，用 `ask_user_question` 工具反问。**只给能点的选项，不给开放式问答题。**

三条纪律：
1. **只问缺的**。用户已经说清的一项不要重复问。
2. **一次问完**，最多 3 个问题，别挤牙膏。
3. **必须给退路**——用户回「你定 / 随便 / 都可以」，立刻按本文末尾的默认值表开跑，不再追问第二轮。

**写选项的原则（重要）**：选项标签要用**能搜到的风格名或专业术语**，
不要用「气声多、音量小」这种描述性口语——用户没法拿它去搜参考资料，
也没法判断那到底是什么声音。标签后面再补一句说明和一个可参考的歌手/曲目。

---

## 问题一：歌曲结构

| 选项标签 | 专业名 / 别名 | 是什么 + 参考 |
|---|---|---|
| **主歌-副歌式** | Verse-Chorus Form | 主歌副歌交替，副歌重复 2–3 次。市面上九成流行歌都是这个，最稳，适合发布 |
| **三十二小节 AABA** | 32-Bar AABA / 爵士标准曲式 | A 段重复两遍 → B 段对比 → 再回 A 段。爵士酒吧、音乐剧、老歌的常见结构 |
| **十二小节蓝调** | 12-Bar Blues | 固定 12 小节循环，三句一段。蓝调、摇滚、早期 R&B 的地基 |
| **渐进爆发式** | Build-up / Drop | 前面铺垫，中段断开，最后副歌所有乐器一起上。电子舞曲、游戏、运动向 |
| **无副歌叙事式** | Verse-only / Ballad | 从头唱到尾，没有反复的大高潮。民谣、叙事曲、当背景音乐不抢注意力 |
| **短循环式** | Loop / Short Form | 主歌副歌各一到两遍，一分半结束。短视频、广告片头 |

**为什么先问结构**：结构决定歌词写几段、`--maxtokens` 给多少、以及时长。
选了短循环却写了四段主歌，会越长越糊；选了主歌-副歌式却只写两段，副歌出不来整首就散了。

---

## 问题二：演唱风格 / 唱法

**每个都是可以自己去搜来听的真实风格名。**

| 选项标签 | 可搜索的风格名 | 声音特点 + 参考 |
|---|---|---|
| **爵士** | Jazz Vocal | 咬音松弛、即兴转音多、常用气声和滑音。参考 Norah Jones、小野丽莎 |
| **灵魂** | Soul / 灵魂乐 | 情绪浓、真假声切换多、即兴装饰音密。参考 Adele、Amy Winehouse |
| **民谣** | Folk Vocal | 自然不修饰，像在讲一件事。参考 Bob Dylan、朴树 |
| **复古流行** | City Pop / 80s J-Pop | 甜而亮、颤音轻、尾音带点沙沙感。参考 杏里、竹内玛莉亚 |
| **蓝调** | Blues Vocal | 拖拍、蓝调音阶、带苦味。参考 B.B. King、Etta James |
| **乡村** | Country Vocal | 鼻音重、颤音明显、咬字清楚 |
| **气声流行** | Breathy Pop | 气声占比高、声音轻。参考 Billie Eilish |
| **实唱流行** | Belt Pop | 胸声扎实、副歌能顶很高。参考 Whitney Houston、邓紫棋 |
| **说唱** | Rap | 有节奏地念词，不是唱 |
| **多人叠唱** | Vocal Layering | 同一个音叠几层人声，听起来像合唱团 |

**为什么问唱法**：同一份歌词，爵士唱法和实唱流行是两首歌。唱法还直接影响歌词的用词——
气声流行的句子要短、多用闭口音；实唱流行的副歌需要开口音多的句子才推得上去。

## 问题三：乐器编制

先按编制规模挑一档，再在档里挑具体风格。

### 小编制（1–4 人，安静、贴近）

| 选项标签 | 具体是哪几件 | 声音特点 |
|---|---|---|
| **钢琴独奏** | 钢琴 | 最干净，人声最清楚 |
| **吉他弹唱编制** | 木吉他 + 轻打击 | 一个人抱着琴在唱 |
| **爵士三重奏** | 钢琴 + 贝斯 + 鼓刷 | 标准 jazz bar 配置 |
| **Bossanova / 拉丁** | 尼龙吉他 + 沙锤 + 康加鼓 + 贝斯 | 摇摆、度假感 |

### 乐队编制（鼓 + 贝斯打底）

| 选项标签 | 具体是哪几件 | 声音特点 |
|---|---|---|
| **流行乐队四件套** | 鼓 + 贝斯 + 电钢琴 + 吉他 | 电台热门歌，最百搭 |
| **City Pop 配置** | 电钢琴 + 贝斯 + 鼓刷 + 萨克斯 | 山下达郎那种，夜晚开车、日式都市感 |
| **蓝调放克四件套** | 电吉他 + 风琴 + 贝斯 + 鼓 | 律动强、摇摆 |
| **摇滚乐队** | 双电吉他 + 贝斯 + 鼓 | 噪、有劲、适合现场感 |
| **独立摇滚** | 独立吉他 + 合成器 + 真鼓 | 清冷、现代 |

### 电子 / 氛围

| 选项标签 | 具体是哪几件 | 声音特点 |
|---|---|---|
| **卧室 Lo-fi** | Rhodes 电钢 + 低保真鼓机 + 磁带噪声 | 学习工作背景音 |
| **Synth-pop** | 合成器 + 鼓机 | 复古未来感、赛博、霓虹 |
| **EDM / 电子舞曲** | 合成器 + 鼓机 + 侧链压缩 | 强 Drop、运动、游戏 |
| **Ambient 氛围** | Pad + 粒子音效（无鼓） | 不抢注意力、冥想过场 |

### 管弦 / 民乐

| 选项标签 | 具体是哪几件 | 声音特点 |
|---|---|---|
| **钢琴加弦乐** | 钢琴 + 小提琴大提琴 + 轻鼓 | 电影配乐感，婚礼、纪念日 |
| **电影配乐编制** | 弦乐组 + 铜管 + 定音鼓 | 宏大、史诗 |
| **新中式 / 国风** | 古筝 + 笛子 + 现代鼓组 | 国风、古装剧配乐 |
| **民乐小编制** | 二胡 + 琵琶 + 古筝 | 素雅、传统 |

**最常用四项**（赶时间就从这四项挑）：流行乐队四件套 / City Pop 配置 /
钢琴独奏 / 卧室 Lo-fi。

**为什么问乐器**：乐器是 caption 里权重最高的一段。写「city pop」不带电钢琴和萨克斯，
模型会给你一首普通流行曲；写「lo-fi」不带 Rhodes 电钢和黑胶噪声，就不 lo-fi。

## 不用问的（从 genre 推）

以下信息通常能从用户给的风格里推出来，**推不出来再问**：

- **BPM** — lo-fi 默认 75–90，city pop 默认 100–110，摇滚默认 120–140，EDM 默认 128。
  除非用户明确说要某个速度。
- **调性** — 大调明亮、小调忧伤；不确定就 C major / A minor。
- **情绪** — 从 genre 和用途推。「背景音乐」默认不抢注意力，「燃向」默认上扬。
- **时长** — 从结构推（见问题一）。
- **采样率 / 码率** — 脚本默认 48kHz，`--format mp3` 即可，不用问。

---

## 默认值表（用户说「你定」时直接用）

| 维度 | 默认 |
|---|---|
| 结构 | 主歌-副歌式 |
| 乐器 | 按 genre 匹配：city pop→City Pop 配置；lo-fi→卧室 Lo-fi；国风→新中式；爵士→爵士三重奏；摇滚→摇滚乐队；电子→Synth-pop；其余→流行乐队四件套 |
| 唱法 | 按 genre 匹配：city pop→复古流行；R&B/lo-fi→气声流行；爵士→爵士；灵魂→灵魂；摇滚/主流流行→实唱流行；民谣→民谣；电子→说唱或气声流行 |
| BPM | 按 genre 默认区间中值 |
| 调性 | 大调明亮、小调忧伤；不确定就 C major / A minor |
| format | mp3 |
| temperature | 0.85（默认）；用户要稳定复现改 0.7 |

## 反问示例

**用户**：「按这个感觉写首歌：城市流行，女声，D 小调」

已给：genre（city pop）、人声（女声）、调性（D 小调）
缺：结构、乐器、唱法、BPM

**该这么问**（用 `ask_user_question`，一次三个问题）：

> **Q1 歌曲结构**（header「结构」）
> - 主歌-副歌式 — 市面上九成流行歌都这样，最稳，适合发布（Recommended）
> - 三十二小节 AABA — 更正宗的 city pop 味，爵士老歌那种
> - 短循环式 — 一分半结束，适合当短视频 BGM
>
> **Q2 乐器编制**（header「乐器」）
> - City Pop 配置（电钢琴+贝斯+鼓刷+萨克斯）— 这个风格的标志性音色（Recommended）
> - 流行乐队四件套（鼓+贝斯+电钢琴+吉他）— 更现代，节奏更强
> - Synth-pop（合成器+鼓机）— 偏赛博未来感，夜晚开车那种
>
> **Q3 演唱风格**（header「唱法」）
> - 复古流行（City Pop）— 甜而亮、颤音轻，参考竹内玛莉亚（Recommended）
> - 灵魂（Soul）— 情绪更浓、真假声切换多，参考 Adele
> - 爵士 — 咬音松弛、转音多，参考 Norah Jones

**用户**：「你定吧」

→ 直接按默认值表：主歌-副歌式 + City Pop 配置 + 复古流行 + 105 BPM + D 小调，
写歌词，进确认环节，不再问第二轮。
